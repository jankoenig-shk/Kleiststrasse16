# Kleiststraße 16

Website zur Sanierung: Haus, Geschosse, Räume mit Bildern und Ladenmappen, Animationen im 3D-Modell, Leistungsverzeichnis.
Veröffentlicht über GitHub Pages (Branch `main`, Ordner `/`). Stand 9. November 2026.

## Aufbau
- `index.html` Startseite · `eg/`, `og/`, `dg/` Geschosse · `raeume/<raum>/` Raumseiten (mit `ladenmappe/`)
- `animationen/` 3D-Modell mit 1-m-Raster, Raummaßen und Rundgang · `lv/` Leistungsverzeichnis (`positionen.csv` für Excel)

Alle Pläne und das 3D-Modell beruhen auf denselben Vektordaten des Architektenplans (1 m = 28,35 pt bei 1:100).
Die Bilder sind Visualisierungen, keine verbindlichen Planunterlagen.
